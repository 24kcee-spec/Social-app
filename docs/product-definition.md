# Product definition (Phase 0)

Status: PROPOSED - edit any line below, then it is frozen until evidence forces a change.

## 0.1 One-sentence definition
A low-pressure social app that helps people in Bulawayo find compatible people, groups and activities, and gives shy users an easy way to start talking.

## 0.2 First audience (pilot)
- NUST students in Bulawayo, invite-only. Pilot size target: 100-300 people (enough density, moderation stays manageable).
- Eligibility rule: to be confirmed in decisions.md (D-007) - proposed: university email or invite code.

## 0.3 MVP (P0 - the only things that ship first)
Auth, profile, interests, discovery, explainable compatibility, low-pressure mode, connection requests, messaging, groups/activities, sharing, block/report, privacy.
Everything else (stories, questions, polls, voice notes, events, memory chains, QR, music, monetisation) goes to the backlog until the pilot shows repeat use.

## 0.4 Brand placeholder
Working name: "social-platform". Neutral design. Real brand is chosen after the pilot.

## 0.8 Success metrics (definitions)
| Metric | Definition | Pilot target (proposed) |
|---|---|---|
| Activation | New user reaches first meaningful interaction (request sent, group joined or activity joined) within 48h of signup | >= 40% |
| Week-1 retention | Signed-up users active again on day 7-8 | >= 25% |
| Connection creation | Accepted connection requests per active user per week | >= 1 |
| Conversations started | Conversations with >= 2 messages from each side | tracked |
| Activities joined | RSVPs per active user per week | >= 0.5 |
| Share rate | Share-link creations per active user per week | tracked |

Targets are starting guesses, not facts; adjust after the first two weeks of real data.
